# Digital-Clock
A modern digital clock built with HTML, CSS, and Vanilla JavaScript. Features a real-time clock, live date display, Start/Stop controls, responsive layout, and a clean dark UI with a neon-inspired design. Perfect for practicing DOM manipulation, Date(), and setInterval(). ⏰
